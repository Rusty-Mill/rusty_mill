## 2026-10-28 - Mill Board side panel is one column

- **Changed:** choosing a repository no longer opens a second column of its projects. The Projects list in the
  panel now names every project of a repository that has several, its own (loose) project included; a repository's
  only project is the repository itself and is not repeated.
