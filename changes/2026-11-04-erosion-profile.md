## 2026-11-04 - Erosion profile: `erosion check` and the claims open rule

- **Added:** the `erosion` binary in `rusty_erosion`, slice 2 of the erosion gate (card #704, D41, D42, D89). `erosion check --base COMMIT` measures the whole Rust tree at the base commit and in the working tree, and prints one JSON line with both levels, the exact deltas, the three worst-affected functions and changed code it cannot measure. With `--report-only` it always exits 0, even when it cannot measure. With `--max-concentration-bp N --max-duplication-bp N` it exits 1 over a limit, which fails the profile through the existing fail-block. Its git calls ignore system and user configuration. It works from the repository root wherever it is started, refuses a repeated flag, and treats Rust that is not UTF-8, in the base or the working tree, as a measurement failure when enforcing (exit 2) and as `unmeasured` when report-only. Rust that is not a regular file (a symlink, FIFO and so on) or whose name is not UTF-8, committed or changed, counts as unreadable Rust and is never read as source. Base blobs are read by object id, so no file name can break the batch, and Rust under a symlinked or replaced directory or inside a submodule counts as deleted, as git sees it; a submodule itself is skipped in both snapshots. Other languages are never read or looked up, only listed.
- **Changed:** `bbp` refuses a claims task `bad_claims_config(erosion)` unless the profile set has exactly one profile named `erosion` that runs the `erosion` bin directly (no shell, `env` or `cargo run` wrapper) with arguments the bin accepts, including exactly one full-commit `--base` that matches any pinned `baseline`, or the new `"erosion": "off"` opt-out. The field is left out when absent, so existing profile digests are unchanged.
- **Known limitations:** nothing goes live yet. The report-only time box and its pause at expiry (D42) come in a later slice, as do the inbox detail (slice 3) and the cleanup trigger (slice 4). A whole-repo run takes about 45 s in a debug build, so a profile's limits need to allow it.
