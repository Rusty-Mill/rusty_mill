## 2026-10-23 - rusty_mux_server

- **Added:** `crates/apps/rusty_mux/crates/server` (`rusty_mux_server`, binary `rusty-mux-server <socket>`). One thread on `rusty_tokio`'s `LocalRuntime`; each block is a PTY running `$SHELL`, read through the reactor and fed to a headless `rusty_term_core` grid. Attaching sends a negotiated RTCP v1 headless checkpoint in 64 KiB chunks, a ready frame, then the raw PTY bytes; input reaches a PTY only from the lease holder, and the terminal's replies to queries go back to the PTY. Clients over an 8 MiB output backlog are dropped rather than stall the PTY. The socket is made owner-only (0600), and a peer whose uid (SO_PEERCRED) is not the server's effective uid is closed before any reply. No tokio in the binary.
- **Added:** `platform_linux::LinuxPty::spawn_concrete` (the trait's `spawn` without type erasure, so the master is `Send + Sync` and pollable) and `LinuxPtyMaster::set_nonblocking`. Both additive; `Pty::spawn` delegates.
- **Fixed (before release):** a flooding PTY starved input; the PTY pump now yields between chunks. Under a background flood a command round-trips in about 5-70 ms in a debug build (`input_round_trips_while_the_pty_floods`, bound 1 s).
- **Known limitations:** Linux only (ConPTY after spike 1). No authentication beyond the same-uid check, no TLS or daemonizing. Closing a session or window is not on the wire yet, only blocks. RTCP v1 requires CHECKPOINT_V1 negotiation; encoded current state is capped at 256 MiB and decoded allocation at 512 MiB, with an 8 MiB live-output transfer tail. Screens are capped at 4096 per axis / 65,536 cells and 4,194,304 potential retained cells; the normal 10,000-row history is preserved. There is no lifetime-output attach cutoff. See docs/projects/mux/REPLAY.md.

- **Fixed (review and owner-approved extension):** Attach preserves full parser/input-mode continuation using a complete headless checkpoint, and encoding failure disconnects before Ready. Child ownership survives setup failure and close through termination/reaping (98979191: separate Process, HUP then KILL after one second, polling reaper; fallback Drop kills and waits). Output budget eviction cancels both connection halves and discards blocked writes/backlogs. Create/resize reject excessive sizes before spawn or mutation.
