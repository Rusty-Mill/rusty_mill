## 2026-11-03 - rusty_mux LLM-readable API help

- **Added:** `rusty-mux-ctl api llms` prints one Markdown document: how to call ctl (targets, `+`, `--json`, exit codes), the commands that are not catalog methods, and every method with its command line, a flag table and its result. It is generated from the catalog, needs no server, and the agent skill points to it.
- **Changed:** ctl's usage text and `api llms` share one table of the non-method commands; `agent` help wraps at a different point.
- **Known limitations:** generated by ctl from the catalog it was built with, so against a newer or older server it describes ctl's methods, not the server's. Not offered through `rusty-mux-mcp`.
