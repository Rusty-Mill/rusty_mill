## 2026-10-23 - Patch tokio for RUSTSEC-2026-0386

- **Security:** tokio 1.53.1 let `tokio::io::unix::AsyncFd` constructors (`new`, `with_interest`, `try_new`, `try_with_interest`) accept any `T: AsRawFd`, violating I/O safety. The root `Cargo.lock` now pins tokio 1.53.3, which restores the `cargo-deny` advisories check on `main`.
- **Known limitations:** lockfile-only change. Cargo also re-selected already-locked versions on existing edges: 21 `windows-sys` edges (Windows-only) and 3 `socket2` edges (`hyper-util`, `quinn`, `quinn-udp`, which also apply outside Windows). No package was added or removed. No independent proof of the upstream fix is claimed beyond the advisory, `cargo-deny` and tests of a tokio `AsyncFd` consumer (`rusty_term`).
