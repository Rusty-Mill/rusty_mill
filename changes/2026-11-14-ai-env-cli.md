## 2026-11-14 - Ai Env Manager CLI (M0 slice 4)

- **Added:** `crates/apps/ai_env_manager/crates/ai_env_cli`, binary `aienv`. `aienv list --skills DIR`, `aienv enable ID --skills DIR [--tool ID] [--yes]` and `aienv disable ID ...` link skills in place into each tool's skills folder from the built-in catalog. Without `--yes` the plan is printed and nothing changes; a path the tool does not own is refused and kept, and the exit code is 1 (usage errors exit 2, other errors 3). `ai_env_fs::discover_skills` finds the skills in a folder. Standard library only.
- **Known limitations:** skills come from `--skills` folders only (git sources and `sources.json` are M1); the catalog is the built-in one (Claude Code, Codex); the Windows junction path is still not run in CI.
