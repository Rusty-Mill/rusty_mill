## 2026-10-13 - Library sources: index entries from other repos

- **Added:** `library/sources.json` lists repos whose skills (`SKILL.md`), mods (plugin folders) and root `prompts/*.md` the library indexes in place. `python3 library/build.py --sync` fetches each source (git over https, shallow, into the git-ignored `.cache/`) and builds; plain `build.py` stays offline and warns about any unsynced source; `--strict` fails on warnings. New modules: `fmt.py` (parsing/reading, moved out of `build.py`) and `sources.py` (validation, sync, scan).
- **Added:** computed provenance `github.com/<repo>@<sha>:<path>` on every remote entry, the repo name as a tag, a "From <repo>" label on cards, remote install hints (`git clone … && claude --plugin-dir …`), and "By source" grouping by `repo@sha`.
- **Added (pilot):** `baileyrd/my_claude_mods` pinned at `e8a8914`: 23 mods, no warnings. The page grows from about 0.2MB to 1.3MB because mod README and hook sources are embedded.
- **Security:** remote content is only read as text and never executed. Symlinks are not followed (a hostile repo cannot make the page embed other files), well-known build/test folders are skipped, sizes are capped with a visible marker, a source cannot set `featured` or `status`, and `repo`, `ref` and `name` are validated (no leading `-`, no `..`, https and github.com only). Mutation checks confirmed the symlink, trusted-key, ref-validation and prune tests each fail when their guard is removed.
- **Verified (run):** 23 library unit tests; a real `--sync` from GitHub at the pinned SHA (1.3s); headless Chromium over the 36-entry page (repo tag filter, card label, provenance, install hint, hook source, one "By source" group of 23, no page errors, stable over three runs).
- **Known limitations:** `sync` is not unit-tested (it needs the network); it was run for real against the pilot. Only GitHub is supported. A plugin's bundled skills are part of the plugin, not separate entries. `CLAUDE.md`/`AGENTS.md` sections are not indexed from sources. Hooks of third-party mods are embedded for reading but never reviewed by the library; they run unsandboxed once installed. CI runs the offline build only, so it does not exercise `--sync`.
