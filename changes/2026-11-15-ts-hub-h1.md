## 2026-11-15 - ts-hub: register and map poll (mesh hub slice H1)

- **Added:** `crates/libs/net/ts-hub`. `GET /key`, `POST /ts2021` (Noise IK upgrade), then HTTP/2 over the Noise channel serving `/machine/register` and the `/machine/map` long-poll with a heartbeat. Nodes register with a pre-auth key and receive a netmap listing the other nodes with their disco keys and endpoints. The node table sits behind a `NodeStore` trait with an in-memory `MemoryStore`; a persistent store is slice H3.
- **Added:** `ts-control` gains the server side of the control handshake (`server_respond`, `accept`, `accept_deferred`), and `ts-types` gains `Serialize` on `RegisterResponse` and `MapResponse` plus `Node::machine_authorized`, which stock clients need before they leave `NeedsMachineAuth`.
- **Not in this slice:** the DERP relay, STUN, TLS, ACLs (every netmap carries an allow-all filter for now) and persistence. See `docs/projects/mux/MESH.md` and the hub build plan. Nothing links `ts-hub` yet.
- **Tested:** the existing `ts-control` client against the hub over real TCP, Noise and HTTP/2 (register, wrong key refused, two nodes see each other's disco keys and endpoints, endpoint change arrives as a new frame).
