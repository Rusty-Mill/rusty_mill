## 2026-10-26 - remind-me: one-call project brief

- **Added:** `remind_me_brief` (MCP, in the `core` profile), `GET /api/brief` and `rusty-remind-me brief PROJECT` return one project's current state (newest session summaries), what is open (blockers raised in the window, decisions and action items with no outcome) and recent activity, newest first, with ids for `remind_me_get`. The project name resolves through the entity graph, so an alias works; a memory is in scope when its project, its git remote's repository, a tag, its subject or object, or an entity link names it. An unknown name is refused with up to five closest known names (`unknown_project`, with `suggestions`), never guessed. `since` takes `7d` (default), `12h` or RFC 3339, up to 365 days. Output is JSON by default (Markdown on request) under a token budget (default 1,500, 200 to 8,000) that bounds the returned text in either rendering (each piece costed as the larger of its JSON and Markdown, bytes/4 rounded up), split across sections by weight with unused share rolling forward; items are dropped whole and counted in `omitted`. Sensitive, superseded, expired and dialog rows never appear and never make a name known or suggested. A project brief needs a non-blank name. Input is strict: unknown fields are refused. Mill Board card #62.
- **Changed:** the SessionStart and UserPromptSubmit hooks now use the same builder. The session brief gains alias-aware scoping, open decisions and blockers, and a 7-day activity window; over budget it drops items rather than whole sections. `rusty-remind-me context --budget` is now in tokens (default 2,000; the hooks pass 2,000 and 750), and its `--json` output is the brief's JSON with the Markdown in `context` (it was `{"context","sections","dropped"}`). The `core` tool profile is now 20 tools.
- **Known limitations:** the brief reads only the store: PR state appears only as far as captures and work logs recorded it. Blockers have no outcome to close them, so only those raised in the window count as open. A plugin hook script older than this build passes a character budget that is now read as tokens, so its brief is larger until the plugin updates.
