## 2026-11-27 - Gateway: per-target upstream modes with session teardown

- **Changed:** an `mcp` target takes `mode: pooled | per_credential | per_session` and `connections: N` (default 8, today's constant). `per_session` gives each downstream session and token principal its own upstream connection or child process. A target with no `mode` is now `per_session` (LEL D102), and `--check` names each one. Set `mode: pooled` to keep the old sharing for a stateless server.
- **Added:** `rusty_mcp_server::ToolSource::session_ended(session)`, a default no-op the HTTP layer calls when a classic session ends by `DELETE` or by going idle. The gateway's federation closes that session's per-session upstreams there, which kills their stdio children.
- **Added:** `rusty_mcp_server::CallContext::session()` and the `ClassicSession` type, both additive (`Caller` is unchanged, so existing `Caller { headers, principal }` literals still compile): the session the server validated for a request (`None` when stateless), with a flag every copy shares that turns when the session ends. The gateway keys `per_session` upstreams on it, not on the raw `Mcp-Session-Id` header, which the server ignores on stateless requests. A call admitted before its session ended opens no upstream afterwards, however long it spent in guardrails; calls queued on a closed upstream, or whose connection was still dialling, are refused; a running call's connection is dropped when that call returns. An upstream a call still holds is not closed for being idle, idle upstreams close on a reaper timer, and `per_credential` keys on the exact credential bytes.
- **Changed:** the `mock_mcp_server` fixture appends its pid when `MOCK_ECHO_PID` is set.
- **Known limitations:** only calls, prompt gets and resource reads are keyed; listings use the first connection. A call with no session (stateless, or classic without `Mcp-Session-Id`) gets a `per_session` upstream for that call alone, so stateless clients pay one connection or child per call there; use `mode: pooled` for a server that keeps no state. Revoked tokens close their sessions in #1382's revocation slice. Approved by Nano as part of D223.
