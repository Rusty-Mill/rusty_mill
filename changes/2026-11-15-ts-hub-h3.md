## 2026-11-15 - ts-hub: persistence and auth (mesh hub slice H3)

- **Added:** `FileStore`, a `MemoryStore` saved to one JSON file (`0600`, written to a temporary file and renamed). A restarted hub keeps its nodes, addresses and spent keys; a corrupt file is an error, not an empty hub. `Hub::with_identity` takes the Noise key (`ts_key::NodeState` already saves one), so nodes keep trusting the hub.
- **Added:** `KeyPolicy { ttl, reusable }` on pre-auth keys. A single-use key is spent by its first machine (that machine may register again); an expired key is refused as `ExpiredAuthKey`.
- **Added:** node expiry (`MemoryStore::with_node_ttl`): an expired node leaves every netmap, its map stream ends at the next keepalive and the relay refuses its next session.
- **Added:** `Hub::revoke(machine)`: the node leaves the table, its map streams end, its live relay session closes, and its machine key is banned (saved with the table), so a reusable or unexpired key cannot bring it back. Ids are never reused; the lowest free address is.
- **Added:** hostnames become unique DNS labels (`My Laptop!` is `my-laptop`, a clash gets `-1`, `-2`).
- **Added:** `Limits::max_map_streams_per_machine` (2), so one registered node cannot take every netmap slot.
- **Changed:** a save that fails rolls back `register` and `add_preauth`; a revoke still holds in memory and reports `Storage`. The table is written to a fresh `0600` temp file and the directory is synced after the rename.
- **Changed:** `NodeStore` takes an explicit `now` (Unix seconds) so the table stays pure and testable, gains `revoke` (returning a `Revocation`), and `add_preauth` takes a `KeyPolicy` and can fail. `Hub::add_preauth` takes a `KeyPolicy` too. `RegisterError` gains `ExpiredAuthKey`, `Revoked` and `Storage`.
- **Not in this slice:** a live relay session of a node that merely *expires* stays up until it reconnects (revoke closes it at once); trust-on-first-use on plain-HTTP `/key` is closed by H5 (TLS); ACLs are H4. No new dependency.
- **Tested:** restart keeps nodes and spent keys, restart keeps a revoke, `0600` file, corrupt file refused, single-use and expiry, expired nodes leave netmaps, revoke closes the relay session and refuses a new one, address reuse without id reuse, hostname sanitizing and de-duplication, the per-machine stream cap.
