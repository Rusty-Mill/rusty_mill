## 2026-11-03 - rusty_orch: orch-codex answers lens questions

- **Added:** `CodexAgent` implements `orch_lens::Model` (Let Em Loose #594). Lens questions are refused as `Unavailable` unless the agent is built with `lens_no_overage()`, the operator's assertion that the account cannot bill beyond its plan; nothing in the adapter can verify that. It is also refused unless the agent is built with `lens_host_cleared()`, the operator's assertion that everything the host lets Codex read is cleared for it: Codex has no tool-less mode and its read-only sandbox reads the whole filesystem, so nothing in the adapter can confine its reads. Each question then checks the auth method: `codex login status` must exit 0 and say `Logged in using ChatGPT`. An API-key login, no login, or anything else is `Unavailable`, nothing runs, and the probe's output (which can show part of a key) never reaches the error. `codex exec` then runs in its read-only sandbox in the repository root with the scrubbed environment, the question's prefix and body on stdin, `--json` events on stdout and the last message to a file inside a private scratch directory (created exclusively, mode 0700 on Unix, removed after). The reply must pass `orch_lens::parse` and report measured usage (at least one `turn.completed` event with integer input and output counts, cached no more than input), or the call is `Permanent`.
- **Changed:** `SCRUBBED_ENV` also removes `CODEX_API_KEY` and `OPENAI_BASE_URL`, for the dispatcher too. The `codex exec` argv is built from one shared base, so the dispatcher's argv is unchanged. `orch-codex` declares rust-version 1.89, the floor of `orch-lens`, and `rusty_json` moves from a dev-dependency to a dependency.
- **Known limitations:** nothing calls it yet. `codex exec` cannot bound its agent loop's tokens before the call, so it runs only at zero price (the lens config refuses any other, ADR-0021). The login check establishes the auth method, not billing; whether a call can be charged rests on the operator's assertion, which runtime approval must verify against the account.
