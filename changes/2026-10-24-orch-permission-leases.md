## 2026-10-24 - rusty_orch: permission leases for hosted goals

- **Added:** `orch_core::factory::Lease` on `Grant`: absolute, normalized read and write paths and an optional end. A leased parent delegates or re-grants only leases it covers, and `Factory::restore` re-checks it for bound children. `Fence` carries the lease of its generation.
- **Added:** the hosting configuration's optional `lease: {read, write, ttl_secs}`. Each `run` takes the assignment over with that lease and a fresh end, durably, before any host command. Lease paths must exist and be canonical, so a child's lease, compared with its parent's by spelling, reaches only what it spells. The BBP host freezes the task's pool with each assigned member's sandbox met with the lease. An unsandboxed assigned member, a checkout outside the lease, or a member path beneath any member's write root (which that harness could swap for a symlink) is refused. A later fence with a lease that reaches other paths is refused, so widening access needs a new task; an ended lease is refused as unavailable. Cancel is never refused for a lease. New acceptance modes `lease-confined`, `lease-unswappable` and `lease-deadline`. ADR-0017.
- **Added:** `bbp mod --deadline-unix SECS`: an absolute end no grace runs past; each harness's `bbp slot-hold` holder kills its group at it, so it holds after the moderator dies. `bbp mod` now refuses to start when any launcher's sandbox root, a system root, the `bbp` directory or a checkout's git directory lies beneath a launcher's write root, or a write root lies in `--work`.
- **Changed:** assignment records are schema v2 in `assignments-v2.mmap`. A goal saved only as v1 loads as unleased, and its next save writes v2; the v1 file is never written again.
- **Known limitations:** no network flag, since BBP has no per-harness network switch to enforce one. A renewal with an earlier end does not shorten a moderator already running. Writers outside the task's own harnesses can still replace a leased root; a process that leaves its harness's group escapes the deadline kill. BBP still adds system roots, the turn workspace and, with `checkout`, the repository's object store. Maintenance cycles host unleased. Fair admission (3d) is a separate slice.
