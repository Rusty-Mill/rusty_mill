## 2026-11-16 - GUI link safety (C63)

- **Security:** Ctrl+click and the Ctrl+Shift+O list used to open http, https, ftp, file and mailto links with no prompt. Now only http/https to a trusted origin opens at once. Other http/https links ask (Cancel, Open once, Always trust). mailto, ftp and file always ask, with no Always trust. Any other scheme is refused with a "Link not opened" notice, and so is a URL that is empty, over 2048 bytes, or holds whitespace, control or invisible (bidi, zero-width) characters, a host that is missing, has `user@`, or is not plain ASCII, a `file:` link to another computer or to a program (.exe, .lnk, .app, .command and so on), and a `mailto:` that attaches a file.
- **Fixed:** on Windows the opener was `cmd /C start "" <url>`, where an `&` in a URL could run a second command. It is now `rundll32 url.dll,FileProtocolHandler`, with no shell.
- **Added:** trusted origins (scheme, host, port) are saved one file per origin in a `trusted_origins/` directory beside `config.toml`. The prompt is the take-over confirm panel, now general, with Cancel focused and the whole URL shown.
- **Added:** the prompt always stays inside the window (narrowed, moved from the edges) and a URL too long to show scrolls with the buttons in view. A failed save of a trusted site no longer trusts it for the rest of the window.
- **Changed:** the prompt's title leads with the host, clicks in the first 300 ms are ignored, a trusted site is one file, written whole under a temp name and hard-linked into place (never replacing another entry), and only trusted if its content matches the hash in its name; two windows or processes can never lose each other's additions or leave duplicates (no lock, no read-merge-write), and a truncated or damaged entry can never trust another site, and a link that fails to start says so; `file:` links also refuse a `//` (UNC) path behind an empty host, names ending in a space or dot, and more program types (msix, iso, vhd, jnlp and others); a damaged slot file is skipped, not fatal.
- **Known limitations:** non-ASCII (IDN) hosts are refused rather than shown as punycode (Q74). An OSC 8 link's visible text is not shown beside its target yet (Q73). There is no Settings row to review or remove trusted origins yet (Q72): delete the origin's file. Other open windows learn of a newly trusted site at their next start.
