## May O11 setup's Skip write anything, such as the commented config template?
Asked 2026-11-04 (PR #1471). **No.** Skip writes nothing (D65): every back-out (Esc, the setup tab's ×, the settings toggle) restores the exact opening values and makes no file or directory writes. A missing config stays missing, so automatic setup returns on the next plain launch (D67) until Finish runs once. Finish is unchanged and writes only values changed from defaults. A Skip that created the template was an interim on #1471 before head 464076c09. The pack never recorded it, and it is not a decision. An explicit "Create a config template" action is a possible later follow-up (Q18), not part of #1471. Tag: answered; D65 is `[stated]`, and the relayed confirmation below adds no new row.
Source: D65 (primary: Nano, "Yes on O11", 2026-11-04 11:44:41Z); D67. Confirmation relayed by reviewer DottiusMaximus in PR #1471 issue comment 6639089600 (2026-11-04 18:46:12Z). ## What constrains O2 hook status (precedence, sandbox, typing into agent panes)?
Asked 2026-11-04 (O2 thread). **Precedence**: D79 (hooks win, OSC fills in), detailed by D81. **Sandbox**: BBP-confined agents cannot reach the mux socket, so their status comes only as OSC 7501 on the pty (term ROADMAP arc 4); `agent hook --event` must fail silent and fast, and a block with no hook records falls back to OSC by itself. **Hook output**: `agent hook` prints only inside a block (mux DECISIONS 2026-10-27 C34), and an event run must print nothing (Claude Code adds `UserPromptSubmit`/`SessionStart` stdout to the model's context). **Outside-repo writes**: C39 writes "a skill and a session-start hook, and nothing else"; new hook entries are K4 writes needing Nano's confirmation on the PR (D80). **Who may report**: any client on the owner-only socket, as for C33 renames (D35); the shared-mode restriction (Q13, card 507) should cover `terminal.report-status` too. **Typing into agent panes**: no constraint; status is display only and pty input is unchanged. That decision is Let Em Loose's to record, not this pack's. **Clean room**: read Orca's README for the rule; copy no Orca code (Q3 open for the mux). Tag: answered.
