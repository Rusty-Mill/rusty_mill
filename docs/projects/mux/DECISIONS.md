| 2026-10-27 | C29's events are `ProgramExited`, `Bell`, `ProgressChanged` and `Notification` (kinds 16–19) behind a new `Features::PROGRAM_EVENTS` (bit 10), separate from `TERMINAL_EVENTS`; an exit is announced only when the program ends by itself, before `BlockClosed`.
