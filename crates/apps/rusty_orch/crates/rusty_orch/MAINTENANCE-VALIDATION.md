# Milestone 2 validation

The [implementation validation record](../../docs/proving/milestone-2-validation.md)
contains the executed checks, actual failures, offline-build limitations and
unexecuted sandbox/live-provider checks. Use the commands in
[MAINTENANCE.md](MAINTENANCE.md) for a fully provisioned checkout.

The milestone is not fully validated until the exact PR head has passing Linux
maintenance acceptance evidence and the required human review.
