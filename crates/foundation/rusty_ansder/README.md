# rusty_ansder

[![CI](https://github.com/baileyrd/rusty_ansder/actions/workflows/ci.yml/badge.svg)](https://github.com/baileyrd/rusty_ansder/actions/workflows/ci.yml)

ASN.1 BER/DER TLV encoder and decoder for **Rusty Mill**, built on
[`rusty_wire`](https://github.com/baileyrd/rusty_wire).

This crate used to also carry an unrelated sovereign RAG/Q&A engine under
this same portmanteau name ("ans" + "der"); that engine now lives in its
own crate, [`rusty_rag`](../rusty_rag).
