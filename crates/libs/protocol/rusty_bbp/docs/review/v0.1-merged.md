# BBP v0.1: Merged Round-Two Review (Claude, ChatGPT, Gemini)

Three fresh-session reviews of v0.1 (`review/v0.1-review-*.md`). All three: BUILD WITH CHANGES. All three agree v0.1 fixed cursor loss, evidence provenance, blob identity and the working-tree gap, and all three find that the v0.1 additions (turn token, attempt generation, candidate binding, runner) are under-specified in ways that break the normal plan-to-merge path. Nobody asked for new roles, kinds or integrations. Findings raised independently by several reviewers come first.

## 3. Raised by one, accepted

- **Fragment length cap** (Gemini F5). Opaque fragments are an R8 bypass. Cap at 128 characters.
- **Ordered diffs** (Gemini F4). Already folded into the manifest fix above.
- **Delta human identity** (Gemini F6). The human channel adapter must verify `kind: human` before emitting any human event; a thread comment is never an approval.
- **Delivery versus live projection** (ChatGPT F9). A superseding message with a different recipient hides both from the original recipient. See the disagreement on `supersedes` below.
- **`closed` before any merge happens; approvals on failed reports** (ChatGPT F10). Require `status: passed` for an `approve` on a candidate, or an explicit human waiver event. `closed` only on a merge receipt naming the merged revision, or rename the state to `approved`.
- **Cancellation, resume targets, moderator crash** (ChatGPT E). Add `cancelled` as a terminal state, enumerate legal `resumed` targets, and state that the moderator rebuilds from the event log.
- **Remove "drop any rule the proving run never exercises"** (ChatGPT F). Safety rules need adversarial tests, not usage counts.
- **Scrub Documenter and Triage from narrative** (Gemini F3 cut). Editorial.

## 4. Disagreements

- **`supersedes`.** Gemini: cut it, append-only plus `reply_to` is enough. ChatGPT: keep it but add a delivery feed with supersession notices. Claude: silent. Recommendation: cut for v0.2. A correction is a `finding` with `reply_to`; the feed ChatGPT proposes costs more than the field saves. Nano decides.
- **`scope: addressed` versus `all` on reads.** Gemini: cut, read everything the capability allows. Others silent. Recommendation: cut; the capability matrix already does the work.
- **Q2, who is R7's second signature.** Claude: any different-vendor agent via `finding` with `reply_to`, keep `verdict` candidate-only. Gemini: any assigned agent of a different vendor. ChatGPT: designated evaluators bound to the decision object, and defer the feature if it delays the proving run. Recommendation: ChatGPT's binding fix is required regardless; defer cross-vendor decisions out of the proving run and keep them in the spec as an optional rule.
- **Q6 deadline.** Two for an independent deadline, one for inheriting. Independent.

## 5. Settled answers to Q1–Q6

- Q1: Coder only.
- Q2: bound proposed-decision object; evaluator set and whether to ship it in the proving run are Nano's call.
- Q3: define what counts first (accepted writes, reads by bytes, rejected attempts separately, control events never), then set numbers. Gemini's starting point: 50 messages, 5 MB, 250 reads, 4 iterations.
- Q4: no.
- Q5: per-blob cap 10 MB, per-task cap, range-read cap; retention is task lifetime plus a fixed window, defined separately from append-only history.
- Q6: own durable deadline.

## 6. What v0.2 must change, in order

1. Split plan authorization from candidate authorization and gate every artifact-producing operation by state and execution token.
2. Replace the role-based turn with an execution token; bind runner writes to the candidate; define `yield_to`.
3. Runner supervisor and sandbox requirements; report discovery via event and card; accounting events.
4. Bind R7 to a proposed-decision object; forbid agent `changes_spec` after plan approval.
5. Manifest pins repo, base, ordered diffs, tree hash; nested-reference validation; fragment cap.
6. Move Delta to an appendix; fix `closed` semantics; add `cancelled`.

The proving run must include a human stub: stale human approval cannot be tested while the gates are deferred.
