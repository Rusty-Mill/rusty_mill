# Maximum instructions per input byte for one `bench_vt_throughput --once`
# pass, counted by cachegrind. Enforced in CI by the rusty-term-bench job:
# `python3 bench/ir_gate.py --bin <release binary>` on
# `gen_workloads.py --size quick`. MB/s in the same job is informational only.
#
# Counts are deterministic for a given binary and input (glibc's memmove
# variant is pinned, see ir_gate.py), so each ceiling is the measured value
# plus 10% headroom for toolchain codegen drift. Ratchet: a PR that lowers a
# workload's count lowers its ceiling to about +10% of the new value.
#

# alt 848.2, ascii 193.2, cursor 127.3, scroll 258.6, sgr 207.8, unicode
# 166.8. alt and cursor keep their ceilings.

# scroll 136.7, sgr 116.7, unicode 167.8 (unicode keeps its ceiling).
