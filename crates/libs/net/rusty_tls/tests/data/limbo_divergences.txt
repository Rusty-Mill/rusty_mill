# classes:
#   looser       this validator accepts, webpki refuses.   A possible forged-certificate
#                acceptance unless limbo expects `ok` (then webpki is the stricter one).
#   stricter     this validator refuses, webpki accepts.  A compatibility cost, or this
#                validator being right when limbo expects `fail`.
#   both-accept  both accept something limbo says to refuse.  Agreement is not correctness.
#
# This file is a ratchet: the test fails on any line not here and on any line here that
# has gone. After understanding a change: LIMBO_BLESS=1 cargo test ... -- --ignored.
