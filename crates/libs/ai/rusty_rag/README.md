# rusty_rag

Sovereign AI Retrieval-Augmented Generation (RAG) & Question Answering
Engine for **Rusty Mill**, connecting search indexing and SIMD vector
embedding retrieval (via [`rusty_simd`](https://github.com/baileyrd/rusty_simd))
for sovereign Q&A.

Split out of `rusty_ansder`, which used to bundle this engine together
with an unrelated ASN.1 DER parser under one portmanteau crate name
("ans" + "der"). The DER parser stayed at
[`rusty_ansder`](../rusty_ansder).
