# Changelog

The crate is not published and carries no version tags, so there is nothing for a
version-keyed changelog to key on.

**[`RELEASE_NOTES.md`](./RELEASE_NOTES.md) is the file to read** — one entry per merged pull
request, newest first, with the reasoning behind each change rather than only the diff.

This file is kept as the conventional landing spot, and as the place a versioned history would go
if the crate is ever published. Adding one is a decision, not a default: see the non-goals in
[`ARCHITECTURE.md`](./ARCHITECTURE.md).
